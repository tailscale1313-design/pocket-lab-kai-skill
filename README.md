# Pocket Lab for Kai 9000

A safe workspace-only skill for reviewing user-selected text reports and producing redacted Markdown remediation notes.

## Install

In Kai, choose **Add Skill from GitHub** and paste:

`https://github.com/tailscale1313-design/pocket-lab-kai-skill`

The main skill file is `pocket-lab-skill/SKILL.md`.

## Included

- `pocket-lab-skill/SKILL.md` — skill instructions
- `pocket-lab-skill/templates/report-template.md` — review template

Pocket Lab stays inside Kai’s normal project workspace. It does not access other apps, private folders, networks, or bypass Kai’s sandbox.
